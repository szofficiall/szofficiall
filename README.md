# DJANGO ORM

I use Django ORM for interacting with relational databases without writing raw SQL for every operation.

```python
Student.objects.all()

Student.objects.filter(city="Kohat")

Student.objects.filter(name__startswith="Su")

Student.objects.exclude(age__lt=18)

Student.objects.get(id=1)

Student.objects.create(
    name="Sultan Zaib",
    age=25,
    city="Kohat"
)

Student.objects.all().order_by("-id")
```

### ORM Workflow

```text
  ↓

  ↓

  ↓
PROCESS
  ↓
DATABASE
  ↓
RESULT
```
